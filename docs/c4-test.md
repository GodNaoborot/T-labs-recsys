# Оценка итоговых моделей на test

Три готовые модели оценены на прежнем test после исправления времени запроса,
без переобучения и подбора. Этот отрезок уже открывался в раннем сравнении.

## Протокол и выборка

Используется [прогноз следующего временного пакета](c4.md):
история строго `original_timestamp < t`, запросы от `285*DAY` до конца журнала.
Следующий целевой пакет должен наблюдаться; конечного GAP нет.

Строка исключается, если любой привязанный like/dislike произошёл раньше `t`.
Разметка сохраняет прежнюю привязку реакций. Группы user-day пересчитаны,
постоянные по label группы удалены.

Общая выборка: **3 160 068 строк / 61 964 группы**, дни запроса 285–300
с нуля (16 дней). Из-за ранних реакций исключена 191 назначенная строка:
label 0 — 5, label 1 — 0, label 2 — 186.

История обновляется по мере доступности событий. У моделей одинаковые строки,
метки, группы и порядок; используются сохранённые train-пороги.

## Время и проверки

Оценка заняла **448.339 с (7.47 мин)**. Пик anonymous RAM процесса
и потомков — **4.931 GiB**.

| Этап | Секунды |
| --- | ---: |
| targets | 20.115 |
| features | 310.958 |
| quantize | 85.646 |
| evaluate | 30.227 |

На 40 фактических test-запросах значения manual49 и всех выбранных DFS-формул
сверены отдельным пересчётом. Свежесть проверена в секундах и float32-днях.
Train-пороги и хеши трёх моделей совпали до и после оценки.

Независимый пересчёт групповых средних и шести интервалов дал максимальные
расхождения 4.5e-15 и 2.1e-16 соответственно.
